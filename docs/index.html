    選定日期的贊成與反對
    原料贊成反對備註
    怎麼投、資料存在哪
    1. 選日期。每天的原料來自儲存庫的 data/days。
    2. 每筆原料選「贊成」或「反對」，備註可留白。不要寫姓名、部門、電話或信箱。
    3. 同一台瀏覽器再按一次會改掉原來的選擇，不會變成兩票。
    4. 下載 JSON 或複製分享連結，交給負責彙總的同事。這是預設、也是不需設定就能用的做法。
    5. 若頁面上出現「送到共享收集端」，那是另外接上的表單或試算表，沒送成功也不影響下載。
