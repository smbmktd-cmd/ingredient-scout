    這個數字只存在這台瀏覽器，還不是團隊總數。

    怎麼投、資料存在哪
    1. 選日期。每天的原料來自儲存庫的 data/days。
    2. 上方搜尋列會找每一天偵察過的原料，不限目前選到的日期。點建議或按 Enter 會打開那一筆的卡片。
    3. 每筆原料選「贊成」或「反對」，備註可留白。不要寫姓名、部門、電話或信箱。
    4. 同一台瀏覽器再按一次會改掉原來的選擇，不會變成兩票。
    5. 這台裝置的表態可下載 JSON 留底。大家的數字看頁面上方的團隊累計。
    6. 若已接上試算表，打開頁面就會看到「團隊累計」，表態後會自動同步。那個數字和「本機」分開。
    7. Formspree 只做收件備份。兩個網址都寫在公開的設定檔，知道網址的人都能送資料。

    欄位定義與每日作業

    表態存在這台裝置的 localStorage，並附一組隨機產生的匿名票號（不是姓名）。清除瀏覽器網站資料後，未同步、未下載的表態會消失。收集端網址若有填，是公開的。
